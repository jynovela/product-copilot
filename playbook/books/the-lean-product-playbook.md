## Key ideas

General knowledge: the points below come from model memory, not from an ingested copy of the book. Check details before quoting or relying on them.

- Product-market fit pyramid: target customer, underserved needs, value proposition, feature set, user experience. See [[product-market-fit-pyramid]].
- Separate problem space (customer needs) from solution space (what you build). See [[product-market-fit-pyramid]], [[opportunity-solution-tree]].
- Find underserved needs by comparing how important a need is with how satisfied customers are today. See [[product-market-fit-pyramid]].
- Test MVPs with customers, iterate, and measure. See [[four-product-risks]].
