# On Writing

- **Author:** Stephen King
- **Topics:** [[communication-and-storytelling]]
- **On the list:** [[2026-01-07-ken-norton-best-pm-books]]

## Why it's on the list

PMs need to write well, and this is how to learn from a master of the craft. (see [[2026-01-07-ken-norton-best-pm-books]])

## Key ideas

General knowledge: the points below come from model memory, not from an ingested copy of the book. Check details before quoting or relying on them.

- Read a lot and write a lot; there's no shortcut.
- Cut: a second draft is roughly the first draft minus 10 percent. Drop adverbs and needless words.
- Write the first draft with the door closed; rewrite with the door open, for readers.

## Use it when

- Writing PRDs, strategy docs and updates
- Editing your own drafts
