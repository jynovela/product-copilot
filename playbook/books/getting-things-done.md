# Getting Things Done

- **Author:** David Allen
- **Topics:** [[self-leadership-and-productivity]]
- **On the list:** [[2026-01-07-ken-norton-best-pm-books]]

## Why it's on the list

PMs juggle hundreds of priorities. The core ideas of this cult classic still help you manage your time. (see [[2026-01-07-ken-norton-best-pm-books]])

## Key ideas

General knowledge: the points below come from model memory, not from an ingested copy of the book. Check details before quoting or relying on them.

- Capture everything in a trusted system so your head is free to think. See [[gtd-workflow]].
- Process inputs: clarify, organize, reflect, engage. See [[gtd-workflow]].
- Define the very next physical action for each project; if it takes under two minutes, do it now. See [[gtd-workflow]].
- Do a weekly review to keep the system trusted. See [[gtd-workflow]].
