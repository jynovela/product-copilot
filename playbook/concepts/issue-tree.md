# Issue tree

## What it is

A logic or issue tree breaks a problem into mutually exclusive, collectively exhaustive (MECE) possible causes (Barrows; Verma on the McKinsey method). Barrows' four steps: define (reframe with others), decompose (logic tree), analyze (collect data per cause, 5 Whys), act (try a fix and recheck). (see [[2026-11-24-research-digest-problem-size]])

## How to use it

- Separate symptoms from root causes; diagnosis needs the full set of symptoms together (Morelli). (see [[2026-11-24-research-digest-problem-size]])
- A symptom seen across people and times points to a systemic cause; a one-off may be temporary (Morelli). (see [[2026-11-24-research-digest-problem-size]])
- Treat each branch as a hypothesis ordered by evidence (Miro: 2 to 5 root-cause hypotheses). (see [[2026-11-24-research-digest-problem-size]])
- Have each person frame the problem alone first, then compare (Hermanto, Torres). (see [[2026-11-24-research-digest-problem-size]])

## Watch out for

- Smalley: no single method (5 Whys, Six Sigma, 8D, A3, DMAIC) fits every problem; troubleshooting, gap from standard, target state and open-ended innovation need different approaches. (see [[2026-11-24-research-digest-problem-size]])
