# Psychological pricing

## What it is

Tactics that change how a price is perceived: charm prices ending in 9, prestige round prices, crossed-out former prices, anchoring with a dearer option, decoy options, and per-day framing. Most evidence in the sources is secondhand or unsourced. (see [[2026-11-24-research-digest-pricing]])

## How to use it

- Charm pricing: Peep Laja cites *Priceless* (Poundstone): the same item at $34, $39 and $44 sold most at $39. (see [[2026-11-24-research-digest-pricing]])
- Show a crossed-out former price; Peep Laja says it beats a 9-ending. (see [[2026-11-24-research-digest-pricing]])
- Anchor with a dearer option: a $3,000 shoe makes an $800 shoe look reasonable (Peep Laja). (see [[2026-11-24-research-digest-pricing]])
- Decoy (Dan Ariely, *Predictably Irrational*): The Economist offered web only $59, print only $125 and print plus web $125; 16 / 0 / 84 chose them. Without the print-only decoy, 68 chose web only and 32 the combo. (see [[2026-11-24-research-digest-pricing]])
- Show value before price; never show a price before explaining the value (Peep Laja). (see [[2026-11-24-research-digest-pricing]])

## Watch out for

- Paddle (a vendor) says 9-endings vs round numbers are inconclusive for tech. (see [[2026-11-24-research-digest-pricing]])
- Two popular claims have no named study: per-day framing "five times more likely to be rated a great deal" and perfume ratings rising when the price doubled (Agnew, via PMA). (see [[2026-11-24-research-digest-pricing]])

## Contradictions

- Peep Laja swaps the Economist prices ("print only $59; web only $125"); PMA and Ariely's original have web only at $59. Use Ariely's version. (see [[2026-11-24-research-digest-pricing]])
