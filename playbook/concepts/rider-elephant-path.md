# Rider, elephant and path

## What it is

General knowledge: The Heath brothers' model: the rider (reason) needs clear direction, the elephant (emotion) needs motivation, and the path (environment) should make the change easy.

## How to use it

- Find bright spots that already work and copy them.
- Shrink the change into a first small step.
- Change the environment so the right action is the easy one.

## Watch out for

- Relying on information alone to change behavior.
