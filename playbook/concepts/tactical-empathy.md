# Tactical empathy

## What it is

General knowledge: Chris Voss's approach: mirror the last few words, label emotions ("it sounds like..."), run an accusation audit, ask calibrated how/what questions, and aim for "that's right".

## How to use it

- Label the stakeholder's concern before arguing.
- Ask "how am I supposed to do that?" instead of saying no.

## Watch out for

- Using the techniques manipulatively; people notice.
