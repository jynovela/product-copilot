# One-way and two-way doors

## What it is

Jeff Bezos's Type 1 and Type 2 decisions, as relayed by the research. Type 1 decisions are irreversible and high-stakes ("tattoo") and need deep thought, data and alignment. Type 2 decisions are reversible ("haircut"): decide fast and adjust. The common mistake is giving Type 2 decisions Type 1 process, which slows big companies; the reverse treats an irreversible call casually. (see [[2026-11-24-research-digest-decisions]])

## How to use it

- Examples given: pivoting strategy or entering a market is Type 1; a new onboarding flow or a time-limited price change is Type 2. (see [[2026-11-24-research-digest-decisions]])
- Walker's grid adds purpose: classify a decision as strategic or operational and by reversibility, and let the class set how much deliberation, participation and authority it gets. (see [[2026-11-24-research-digest-decisions]])
- Frame and size rigorously only for one-way doors such as a new market, platform migration or sunsetting; use light experiments for two-way doors (noirbook, see [[2026-11-24-research-digest-problem-size]]). (see [[2026-11-24-research-digest-decisions]])
