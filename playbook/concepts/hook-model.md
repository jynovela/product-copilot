# Hook Model

## What it is

General knowledge: Nir Eyal's four-step loop: a trigger (external, then internal) prompts an action; a variable reward follows; the user invests something (data, content, effort) that loads the next trigger.

## How to use it

- Map your core loop onto the four steps.
- Ask whether you are helping users or exploiting them.

## Watch out for

- Engagement that users later regret.
