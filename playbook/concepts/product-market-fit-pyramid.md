# Product-market fit pyramid

## What it is

General knowledge: Product-market fit is built from five layers, bottom up: target customer, underserved needs, value proposition, feature set, user experience. The bottom three are the problem space; the top two the solution space.

## How to use it

- Write down each layer as a hypothesis.
- Find underserved needs by scoring importance against current satisfaction.
- Test MVPs against the value proposition, then iterate.

## Watch out for

- Starting at the feature layer without a clear target customer.
