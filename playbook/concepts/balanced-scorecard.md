# Balanced scorecard

## What it is

Combines the financial perspective with customer, internal process, and learning and growth perspectives, so intangible assets such as research capability and customer relationships get measured (HBS Online on Robert Simons; NetSuite). The Balanced Scorecard Institute's Measure-Perform-Review-Adapt method builds a whole metric system on it. (see [[2026-11-24-research-digest-metrics]])

## How to use it

- HBS test: could someone infer the strategy from the scorecard? (see [[2026-11-24-research-digest-goals]])
- Document each measure in a data definition table so it is calculated the same way every period (BSI). (see [[2026-11-24-research-digest-metrics]])
- Set a target and upper and lower thresholds that define green, yellow and red (BSI). (see [[2026-11-24-research-digest-metrics]])
- Pick a direct measure of the result first; if none exists, use indirect measures built on a stated hypothesis (BSI). (see [[2026-11-24-research-digest-metrics]])

## Watch out for

- "If you don't know what you are trying to accomplish, it is too early for KPIs" (BSI). (see [[2026-11-24-research-digest-metrics]])
- BSI's method is the consultancy's own, wrapped in a sales pitch. (see [[2026-11-24-research-digest-metrics]])
