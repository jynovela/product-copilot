# Fogg behavior model

## What it is

General knowledge: BJ Fogg's model: behavior happens when motivation, ability and a prompt come together at the same moment. If an action doesn't happen, one of the three is missing. Making the action easier is usually more reliable than raising motivation.

## How to use it

- For a step users skip, check which of motivation, ability or prompt is missing.
- Make the action easier before trying to motivate people more.
- Put the prompt where the user already has motivation and ability.

## Watch out for

- Adding reminders to an action that is too hard.
- Using it to push behavior users don't want.

## What the framework articles say

These are vendor and practitioner articles, not neutral sources.

- Listed as a model for how to get users to take action. (see [[linkedin-10-pm-frameworks-post]])
- Formally introduced in 2007; B=MAP; motivation and ability trade off, shown as an action line; three core motivators (sensation, anticipation, belonging), six ability factors (time, money, physical effort, mental effort, social deviance, non-routine) and three prompt types (spark, facilitator, signal). (see [[2025-06-13-growth-engineering-fogg-behavior-model]])
- Limits: motivation is more complex than the model shows, it focuses on the moment rather than long-term change, and it can be used to manipulate. (see [[2025-06-13-growth-engineering-fogg-behavior-model]])
