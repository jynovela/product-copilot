# Story map

## What it is

General knowledge: Jeff Patton's technique: arrange user activities left to right in journey order (the backbone), list user stories under each, then slice horizontally into releases that each give users a complete, usable outcome.

## How to use it

- Build the map with the whole team.
- Slice the thinnest release that lets users finish the journey.

## Watch out for

- Treating the map as a backlog instead of a conversation tool.
