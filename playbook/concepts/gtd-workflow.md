# Getting Things Done workflow

## What it is

General knowledge: Capture every commitment in a trusted system; clarify each into a next action; organize by project and context; review weekly; then choose what to do. Two-minute tasks get done immediately.

## How to use it

- Capture all incoming requests in one inbox.
- Write the next physical action for each project.
- Do a weekly review.

## Watch out for

- A system you don't trust, so you keep things in your head.
