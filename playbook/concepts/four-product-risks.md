# Four product risks

## What it is

General knowledge: Before building, check: Will customers buy or use it (value)? Can they figure it out (usability)? Can we build it (feasibility)? Does it work for the business: legal, sales, finance, brand (viability)?

## How to use it

- For each idea, write which risk is largest.
- Test that risk first with the cheapest prototype or experiment.
- PM owns value and viability; design owns usability; engineering owns feasibility.

## Watch out for

- Testing only usability and assuming value.
