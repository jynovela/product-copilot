# Affordances and signifiers

## What it is

General knowledge: Affordances are the actions an object allows; signifiers show where and how to act. Good design adds mapping, feedback, constraints and a clear conceptual model so people know what to do and whether it worked.

## How to use it

- In reviews, ask: how does a user know they can do this? How do they know it worked?
- Treat repeated user errors as design bugs.

## Watch out for

- Blaming users for errors the design invites.
