# Build-measure-learn

## What it is

General knowledge: The Lean Startup loop: turn ideas into the smallest product that tests a hypothesis, measure real behavior with actionable metrics, and decide to pivot or persevere.

## How to use it

- Write the hypothesis and success metric before building.
- Build the smallest thing that tests it.
- Decide pivot or persevere on evidence.

## Watch out for

- Calling an unfinished product an MVP without a hypothesis.
- Vanity metrics.
