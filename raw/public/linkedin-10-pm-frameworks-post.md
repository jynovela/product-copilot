# 10 helpful PM frameworks (LinkedIn post): framework extract

- Source: A LinkedIn post; author not shown in the paste
- Date: not shown
- Pasted into the project by the user on 2026-11-20
- This file keeps only short paraphrases of what the article says about each framework. The article's own text is not copied here.

- **Five whys**: Listed as a way to get to the root of a problem.
- **First principles thinking**: Listed as a way to become a clear thinker and problem solver.
- **Fogg behavior model**: Listed as a model for how to get users to take action.
- **Eisenhower matrix**: For managing time and initiatives.
- **AARRR (pirate metrics)**: Breaks the user journey into stages.
- **HEART framework**: Google's framework for understanding feature success.
- **jobs-to-be-done**: Helps you understand why people use a product.
- **okrs**: Sets measurable objectives and an action plan.
- **mom-test-interviews**: Listed as a way to ask better questions and get better insights.
