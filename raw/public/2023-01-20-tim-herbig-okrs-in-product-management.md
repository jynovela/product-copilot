# A Practical Guide to Using OKRs in Product Management: framework extract

- Source: Tim Herbig (herbig.co)
- Date: 2023-01-20
- Pasted into the project by the user on 2026-11-20
- This file keeps only short paraphrases of what the article says about each framework. The article's own text is not copied here.

- **opportunity-solution-tree**: Product discovery answers two questions: is this a problem worth solving, and which solutions are worth pursuing.
- **okrs**: Uses Christina Wodtke's definition: two to five key results per objective. Without a clear product strategy, OKRs don't make sense. Outcomes are changes in behavior; output key results are sometimes fine, especially as leading indicators. Strict cascades push teams toward outputs; quarterly cycles are a habit, not a rule.
