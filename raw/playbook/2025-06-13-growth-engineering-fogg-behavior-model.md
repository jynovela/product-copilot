# The Fogg Behavior Model: How to Turn Learning into Action: framework extract

- Source: Harry Cloke, Growth Engineering
- Date: 2025-06-13
- Pasted into the project by the user on 2026-11-20
- This file keeps only short paraphrases of what the article says about each framework. The article's own text is not copied here.

- **Fogg behavior model**: Formally introduced in 2007; B=MAP; motivation and ability trade off, shown as an action line; three core motivators (sensation, anticipation, belonging), six ability factors (time, money, physical effort, mental effort, social deviance, non-routine) and three prompt types (spark, facilitator, signal).
- **Fogg behavior model**: Limits: motivation is more complex than the model shows, it focuses on the moment rather than long-term change, and it can be used to manipulate.
